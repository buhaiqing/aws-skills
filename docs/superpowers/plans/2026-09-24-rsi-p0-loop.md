1. **gen（并行 3）**：三个 Generator 在 worktree 内按 spec §4 实现 + 写测试。不改他人文件；不 commit（由 Orchestrator 顺序提交避免 git index 竞争）。
2. **critic（并行 6）**：每个子任务 2 个 Critic —— C-1 正确性/测试保真，C-2 门禁·安全·跨模块契约（重点查 spec §3 C1-C5）。
3. **fix**：≤3 轮，Generator 修复后回归测试。
4. **aggregate**：Orchestrator 顺序 commit（每子任务一个原子 commit）→ final reviewer 查跨模块契约（`_library_signatures` jsonl 兼容、默认路径一致性、CSV schema 一致）。
