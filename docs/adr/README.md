# Architecture Decision Records

ADR 记录影响仓库长期方向、跨模块边界或不可轻易逆转的工程决策。

## 状态

- `Proposed`：等待评审。
- `Accepted`：已批准，进入执行。
- `Superseded`：被后续 ADR 替代。
- `Deprecated`：不再适用，但保留历史。

## 命名

`NNNN-<short-title>.md`，编号单调递增。每份 ADR 至少包含 Context、Decision、Consequences、Delivery、Metrics 和 Revisit 条件。
